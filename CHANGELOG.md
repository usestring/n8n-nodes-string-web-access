# Changelog

## 0.1.0

Initial release.

- **Page → Fetch**: retrieve a URL as Markdown, a JSON envelope or its original body, with
  JavaScript rendering, proxy country, CAPTCHA solving, custom headers and Markdown controls.
- **Page → Send Request**: send a POST, PUT or PATCH with a body and return the response.
- **Web → Search**: query Google, Brave, DuckDuckGo or Mojeek, with a simplified output that
  emits one item per result.
- **Site → Map**: quote and run a same-site crawl, then return each discovered URL as its own item.
  The quote can be returned without starting the crawl.
- **String Web Access API** credential: API key held as a password field and sent as a bearer
  token, with a credential test that is never billed.
